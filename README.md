# Lexicoin — a ScrabbleBot auction bot

Team **Tai Force** · bot **Lexicoin** · built for Spacetime's ScrabbleBot Tournament
(https://scrabblebot.spacetimedb.com/).

See `bot/` for the bot, `bot/src/strategy.ts` for the strategy, `bot/src/sim.ts`
for the offline simulator used to tune it.

```bash
cd bot && npm install
BOT_NAME=Lexicoin BOT_TOKEN=<token from /team> npm start
```
